# 「돈의 나이테」 계기판 시계열 — 산출 근거 (2026-11-26)

그 값에서 나온 최저·최고·현재 위치를 남긴다. 계기판의 막대는 **이 폴더의 원자료에서만** 나온다.

- 화면 코드: `src/data/money-lens.ts`의 `lensGauges()` · `src/components/money-lens/LensBoard.tsx`

## 2. 계산

```
원화 금가격(g) = 국제 금 월평균($/oz) × 같은 달 월평균 환율 ÷ 31.1034768
예금 누적배수  = 첫 달 1.000, 이후 매달 (1 + 그 달 창 평균금리/100)^(1/12) 을 곱한다
1억 배수       = 자산별로 2016. 11. 값을 1.0으로 둔 배수
   · 서울 아파트 = 지수 ÷ 2016. 11. 지수
   · 원화 예금   = 예금 누적배수
   · 달러 1억    = 환율 ÷ 2016. 11. 환율
   · 금 1억      = 원화 금가격 ÷ 2016. 11. 원화 금가격
단위별 시계열  = 1억 배수 ÷ 그 달의 단위가격(달러 = 환율, 금 = 원화 금가격)
현재 위치(%)   = (지금 값 − 창 최저) ÷ (창 최고 − 창 최저) × 100   (0~100으로 자름)
   · 지금 값은 화면의 다른 숫자와 같은 점값(환율 1,342.41 · 금 176,503.2)을 쓰되,
     나누는 기준은 시계열과 같은 2016. 11. 월평균이다(그래야 점선 위치가 시계열 위에 있다).
   · 창 = 10년(120개월, 2016. 11.~2026. 10.) 또는 5년(60개월, 2021. 11.~2026. 10.)
수익률(화면 오른쪽 %) = lensCross() — 원화수익률을 그 단위의 상승분으로 나눈 값
   · 예) 서울 아파트 원화 +42.9%, 달러 +25.4%, 금 −62.5%
```

## 4. 한계 (화면 각주와 같은 내용)

- 환율·금은 **월평균**이다. 오늘의 점값(1,342.41원)과 몇 원 차이가 날 수 있다.
- 금값은 국제 금 월평균 × 그 달 평균 환율로 환산한 계산값이다. 국내 판매가에는 부가세·수수료·프리미엄이 붙어 더 높다.
- 아파트는 **가격이 아니라 지수**다. 103.64는 "2026. 06. 대비 +3.64%"라는 뜻이고, 1억 환산은 성립하지 않는다(화면 `오늘` 탭에 그렇게 적었다).
- 예금은 세전이다(이자소득세 15.4% 미반영).
- 위치(%)는 "저점~고점 사이 어디"라는 뜻일 뿐, 앞으로의 방향을 말하지 않는다. 투자 권유가 아니다.

## 5. 재생성 · 검증

```
python3 reports/buffetkimz-web/lens-tracks/build_tracks.py          # TS 재생성 + 최저/최고 출력
python3 reports/buffetkimz-web/lens-tracks/build_tracks.py --check  # 파일이 그대로인지 확인
cd apps/buffetkimz-web && npm run build:pages && python3 scripts/verify_lens.py
```

`verify_lens.py` L14가 위 표를 **파이썬으로 다시 계산해** 산출물의 `aria-label`(위치 %)과 1.5%p 안에서 대조한다.
원자료를 갱신하면 `LENS_VINTAGE.refreshedAt`과 이 문서의 표도 함께 고친다.
